This section presents the expected results for the $WH$ \zdom{} and \zdep{} categories individually, the combined $WH$ channel, the $ZH$ channel, the combined Run~3 results, and finally the combined Run~2 and Run~3 results. Observed results will only be presented for the \wh{} categories and their combination since the \zh{} channel is still blinded as of writing this thesis. For the Run~3 combination, all sources of systematic uncertainty are treated as fully correlated. In the Run~2 and Run~3 combination, a different correlation scheme is adopted, following the approach used in a recent $HH \to bb\gamma\gamma$ publication~\cite{ATLAS:2025hhd}. The scheme is defined as follows:
\begin{itemize}
  \item Trigger uncertainties are treated as fully uncorrelated,
  \item Luminosity uncertainties are treated as fully uncorrelated,
  \item Electron/$\gamma$ uncertainties are treated as fully uncorrelated,
  \item Jet Flavor-tagging uncertainties are treated as fully uncorrelated,
  \item Jet and \met{} uncertainties are taken as fully correlated, except for the Jet InSitu NonClosure PreRec uncertainties, which are fully uncorrelated,
  \item Muon uncertainties are taken as fully correlated,
  \item Theory uncertainties are taken as fully correlated.
\end{itemize}

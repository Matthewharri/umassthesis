The Monte Carlo (MC) signal samples for this thesis consist of $WH$ and $ZH$ production where the associated bosons decay leptonically, and the Higgs boson decays into two $W$ bosons that decay leptonically. The event generator used to model these is POWHEG-BOX~\cite{powheg} with MINLO~\cite{minlo} for the hard-scattering matrix element calculations at next-to-leading order (NLO) in QCD, interfaced with Pythia 8.3~\cite{pythia8.3} using the A14 tune~\cite{ATL-PHYS-PUB-2014-021} to simulate parton showering, hadronization, and the underlying event. The PDF4LHC21 parton distribution function (PDF) set~\cite{PDF4LHCWorkingGroup_pdfsetrun3} is used in the event generation to describe the proton structure. Matrix elements are matched to the parton shower using the POWHEG matching scheme. During event generation, the associated boson is forced to decay leptonically, which is taken into account in the cross section calculation. The Higgs boson mass is set to 125 GeV in all samples with the uncertainty in the mass being negligible. These are summarized in Table~\ref{tab:mc_signal_samples}.

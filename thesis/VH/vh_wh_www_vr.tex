In the on-shell SM $WWW$ analysis from Run 2, an excess of about 2.5$\sigma$ was seen for $WWW + WH$ events. This excess was further confirmed in the Run~2 $WH$ analysis within the \zdep{} channel, where $WWW$ constitutes a significant background. The excess was mostly seen in the $WWW$ output node, and appeared to be strongly enhanced with events containing one jet. Additionally, when the $b$-tagged jet veto was inverted, the excess disappears. To account for a similar excess potentially appearing in the Run~3 data, a dedicated $WWW$ VR is defined to help constrain this background in the final fit. The VR overlaps with the \zdep{} SR by using the same event selection with an additional requirement that the $WWW$ node of the \zdep{} ANN exceeds 0.4. This value was chosen to obtain a high $WWW$ purity and low contamination from $WH$. These values are summarized below in Table~\ref{tab:vh_wh_www_vr}.

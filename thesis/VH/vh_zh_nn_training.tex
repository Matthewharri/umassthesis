This section provides a brief overview of the ANN training for the \zh{} analysis and omits many of the details already discussed for the \wh{} analysis.

The training procedure follows the prescription outlined in Chapter~\ref{ch:nn}. A separate training is performed for each SR using the same set of input variables listed in Table~\ref{tab:vh_zh_input_variables}, with the corresponding hyperparameters summarized in Table~\ref{tab:vh_zh_architecture}. Some input variables are defined in the Higgs boson rest frame, which may initially seem counterintuitive given the presence of two undetected neutrinos in the final state. To construct this rest frame, the boost of the associated $Z$ boson is first determined from its two charged leptons, with all jets assigned to the $Z$ boson system. The Higgs boson rest frame is then approximated by boosting along the direction opposite to the reconstructed $Z$ boson boost. In both SR's, the ANN is trained as a binary classifier, with one output node representing the probability of a \zh{} signal event and the other the probability of a background event.
